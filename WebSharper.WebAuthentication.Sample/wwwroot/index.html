WebAuthn Demo

Register and authenticate a public-key credential with the Web Authentication API. The page must run in a secure context (HTTPS or localhost) with a platform authenticator, a security key, or a virtual authenticator.

1. Register

Creates a new credential with navigator.credentials.create() using the ES256 (-7) algorithm.

2. Authenticate

Requests an assertion with navigator.credentials.get() for the credential created above.
